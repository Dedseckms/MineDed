# Правила сообщества

Этот документ основан на [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
и действует в репозитории MineDed (issues, pull requests, обсуждения) и в общем чате лаунчера.

## Наше обещание

Мы хотим, чтобы участие в проекте было комфортным для всех, независимо от возраста, опыта, внешности,
национальности, пола, религии и других личных качеств.

## Как себя вести

- Уважайте других, даже если не согласны.
- Критикуйте идеи и код, а не людей.
- Помогайте новичкам и отвечайте по существу.
- Признавайте ошибки и учитесь на них.

## Что недопустимо

- Оскорбления, мат в общих местах, травля, угрозы.
- Публикация чужих личных данных без согласия.
- Спам, реклама, накрутки.
- Сексуализированный контент и домогательства.
- Обход блокировок и банов с других аккаунтов.

## Как сообщить о нарушении

- В лаунчере — кнопка **«Пожаловаться»** на сообщении.
- На GitHub — пожаловаться на комментарий через меню **Report content** или написать модераторам
  приватно через **Security → Report a vulnerability** с пометкой «нарушение правил».

Все обращения рассматриваются конфиденциально.

## Последствия

В зависимости от тяжести: предупреждение, удаление сообщения, временный мут, постоянный бан в чате
и/или в репозитории.

---

**English.** This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful; harassment, slurs, doxxing and spam are not tolerated. Report issues via GitHub "Report content"
or privately via Security → Report a vulnerability.
