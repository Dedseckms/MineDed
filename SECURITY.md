# Безопасность / Security

## Поддерживаемые версии

Исправления безопасности выходят только для **последней версии** MineDed. Лаунчер обновляется сам,
поэтому держите автообновление включённым.

## Как сообщить об уязвимости

**Не создавайте публичный issue.** Сообщите приватно через GitHub:
вкладка **Security** → **Report a vulnerability**
(<https://github.com/Dedseckms/MineDed/security/advisories/new>).

Опишите, пожалуйста:
- что затронуто (лаунчер, сервер скинов, сервер комнат, сайт) и версию;
- как воспроизвести и что можно сделать с уязвимостью;
- при возможности — предложение по исправлению.

Мы ответим в течение 7 дней, сообщим о сроках исправления и, если хотите, укажем вас в описании релиза.

Пожалуйста, не проверяйте уязвимости на чужих аккаунтах, не нагружайте серверы и не публикуйте детали
до выхода исправления.

---

**English.** Please report vulnerabilities privately via GitHub: **Security → Report a vulnerability**.
Do not open public issues for security problems. Only the latest release is supported.
