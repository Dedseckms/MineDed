## Что сделано в этой партии
1. **Серверный аккаунт приоритетнее гостя** (чат).
   - `ChatService::server_account` — новый метод: отдаёт аккаунт своего сервера, игнорируя сохранённого гостя.
   - `ChatClient::session()` больше не заменяет аккаунт гостём; `connect()` сбрасывает `me` до проверки.
   - UI (`useSocialSync`, `ChatScreen`) сперва пробует аккаунт, гость — только когда аккаунтов нет.
2. **Настройки → «Мои данные»**: `app_reset_data` (аккаунты+токены, инстансы, кэш, папка игры) с подтверждением.
   Хук деинсталлятора NSIS не делали — это `tauri.conf.json` (зона release).
3. **Быстрый список модов**: `content_list` теперь без сети; бейджи и слаги — `content_marks`
   (пакетные запросы: CurseForge `POST /mods` по 50 id, Modrinth `GET /projects?ids=[...]`).
   Причина тормозов была в N+1 запросах на каждый мод через прокси VPS.
4. **Счётчик онлайна**: первый heartbeat сразу при старте, не останавливается при выходе из чата.

## Правила, которые нельзя нарушать
- В репозитории нет VPN в текстах, нет упоминаний Claude/агентов, секретов.
- `bindings.ts` только генерацией: `cargo test -p desktop export_bindings` (в один поток!).
- Сборка: `cargo` падает с `0xc0000409`/LNK1102 при параллельности — только `-j 1` (максимум `-j 2`).
- Диск: после работы удалять `target/` в ворктри (`du -sm`), иначе C: забивается.
