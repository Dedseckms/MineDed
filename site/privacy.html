Политика конфиденциальности

Обновлено: 27 октября 2026 г. · English version below

MineDed — бесплатный лаунчер Minecraft с открытым исходным кодом. Мы собираем только то, что нужно для работы функций, ничего не продаём и не показываем рекламу. В лаунчере нет аналитики и телеметрии.

Что хранится на вашем компьютере

  • Сборки, моды, настройки и журналы лаунчера — в папке данных лаунчера.
  • Токены входа в аккаунт — в защищённом хранилище ОС (Windows Credential Manager / Secret Service).

Что хранится на наших серверах

  • Аккаунт «Мой сервер» (сервер скинов): ник, хеш пароля (сам пароль не хранится), идентификатор игрока, скины и плащи, использованный инвайт.
  • Комнаты для совместной игры: код комнаты и список участников — только пока комната существует. Игровой трафик идёт напрямую между игроками в зашифрованном виде; если прямое соединение невозможно, он проходит через наш ретранслятор в зашифрованном виде, и мы не можем его прочитать.
  • MineDed VPN (если вы его включили): объём трафика за месяц — для лимита. Мы не храним, какие сайты и сервисы вы посещаете.
  • Чат (когда появится): сообщения, фото и файлы хранятся, пока вы их не удалите; резервная копия хранится на втором сервере.
  • Технические журналы веб-серверов (IP-адрес, время, адрес запроса) — для защиты от атак и поиска ошибок, хранятся ограниченное время.

Серверы расположены в Германии.

Сторонние сервисы

Лаунчер напрямую обращается к Mojang (файлы игры), Modrinth (моды и сборки), GitHub (обновления лаунчера) и, по вашему запросу, к сайтам скинов. На эти запросы распространяются политики этих сервисов.

Ваши права

Вы можете в любой момент удалить свои скины и сообщения, а также попросить удалить аккаунт со всеми данными. Напишите нам приватно через GitHub: Security → Report a vulnerability с темой «Удаление данных» и укажите ник.

English

MineDed is a free, open-source Minecraft launcher. It contains no analytics or telemetry and shows no ads. Locally it stores your instances, settings, logs and login tokens (in the OS credential store). Our servers (in Germany) store: for own-server accounts — username, password hash, player UUID, skins and capes; for multiplayer rooms — the room code and participants while the room exists (game traffic is end-to-end encrypted, relayed only when a direct connection fails); for MineDed VPN — monthly traffic volume only, no browsing history; for chat (when released) — messages and files until you delete them, with a backup on a second server; web server logs (IP, time, URL) for a limited time. The launcher talks directly to Mojang, Modrinth, GitHub and, on request, skin websites. To delete your account and data, contact us privately via GitHub Security → Report a vulnerability with the subject "Data deletion".
