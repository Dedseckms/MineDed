MineUP

A fast, free Minecraft launcher with mods, skins, multiplayer by room code and a built-in VPN.

Download Source on GitHub

Windows 10/11 and Linux · free and open source (GPL-3.0)

Everything in one launcher

  • Versions & loaders

    Any Minecraft version, plus Fabric, Quilt, Forge and NeoForge in one click. Java is installed automatically.

  • Mods & modpacks

    Browse Modrinth right in the app: mods, modpacks, resource packs and shaders with dependencies resolved.

  • Own skin server

    Upload skins and capes, see them in 3D, and everyone on the server sees them too. No Microsoft account required.

  • P2P multiplayer

    Create a room, share the code, play together. Direct connection with relay fallback, no port forwarding.

  • Voice & chat

    Built-in room chat and voice with push-to-talk and an in-game overlay.

  • VPN & anti-blocking

    Downloads and services keep working where they are blocked: built-in VPN, mirrors and smart routing.

  • Low-end PC mode

    A light mode without heavy effects, plus tuned memory and JVM flags for weak hardware.

  • Auto-updates

    The launcher updates itself in the background with signed releases.
