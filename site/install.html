Как установить MineDed

Скачивайте лаунчер только с этого сайта или со страницы Releases на GitHub. Копии из других мест могут быть изменены.

Windows 10 / 11

  1. Скачайте установщик .exe (рекомендуется: права администратора не нужны) или .msi.
  2. Браузер пишет, что файл скачивают редко? В Chrome / Edge нажмите «⋯» у загрузки → «Сохранить».
  3. «Windows защитила ваш компьютер» (SmartScreen): нажмите «Подробнее» → «Выполнить в любом случае». Это предупреждение появляется, потому что у установщика пока нет платной цифровой подписи и мало скачиваний, — вируса в нём нет. Код открыт, установщики собирает GitHub Actions.
  4. Пройдите установщик — ярлык появится на рабочем столе и в «Пуске».
  5. Брандмауэр Windows при первой игре с друзьями спросит про доступ к сети для MineDed и Java — разрешите для частных сетей, иначе друзья не смогут подключиться.
  6. Режим VPN «Выбранные программы» спрашивает права администратора — это нормально.

Linux

AppImage — работает на любом дистрибутиве и обновляется сам:

chmod +x MineDed_*_amd64.AppImage && ./MineDed_*_amd64.AppImage

Ошибка про FUSE — установите пакет: Ubuntu 22.04 / Debian / Mint — sudo apt install libfuse2; Ubuntu 24.04+ — libfuse2t64; Arch / CachyOS — sudo pacman -S fuse2; Fedora — sudo dnf install fuse-libs.

.deb (Ubuntu, Debian, Mint): sudo apt install ./MineDed_*_amd64.deb — новые версии ставятся так же.

Чёрное окно на старых видеокартах: запустите с WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1 перед командой.

Первый запуск

  1. Аккаунты → оффлайн-аккаунт (просто ник) или «Мой сервер» — вход по инвайту, со скинами.
  2. Сборки → «Создать»: версия и загрузчик. Java скачается сама.
  3. Играть. Для слабых ПК — пресет оптимизации в настройках сборки.

Обновления лаунчер предлагает сам при запуске; они подписаны, подменённое обновление не установится.

Где лежат данные

  • Windows: %APPDATA%\ru.dedseckms.mineup, логи — %LOCALAPPDATA%\ru.dedseckms.mineup\logs
  • Linux: ~/.local/share/ru.dedseckms.mineup (логи — в папке logs)
  • Лог игры — «Играть» → «Лог игры». Прикладывайте его к сообщению об ошибке.

Удаление

Windows: Параметры → Приложения → MineDed → Удалить; сборки и миры остаются в папке данных. Linux: удалите AppImage или пакет .deb через sudo apt remove.

English

Windows: run the .exe installer (no admin rights) or the .msi. If SmartScreen shows "Windows protected your PC", click More info → Run anyway — the installer isn't code-signed yet; the source is open and builds come from GitHub Actions. Allow MineDed and Java on private networks when the firewall asks.

Linux: chmod +x MineDed_*_amd64.AppImage and run it (install libfuse2 / fuse2 if FUSE is missing), or sudo apt install ./MineDed_*_amd64.deb. Black window on old GPUs: start with WEBKIT_DISABLE_DMABUF_RENDERER=1 WEBKIT_DISABLE_COMPOSITING_MODE=1.
